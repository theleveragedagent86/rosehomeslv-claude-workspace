# Codename History, Character Library

Persistent, cross-episode cast. Reuse these sheets in every episode. Only add a new row when a script introduces a genuinely new character; draw it to the house-style bible below.

## House-style bible (drop into every sheet + still prompt)

```
flat 2D vector cartoon, OverSimplified style, bold clean black outlines, solid
flat fills, no gradients or shading, muted historical palette; simple rounded
proportions, expressive dot eyes; non-photorealistic, no realism, no text.
```

Each sheet: full-body, neutral pose, plain background, so it can serve as an image ref for later stills.
