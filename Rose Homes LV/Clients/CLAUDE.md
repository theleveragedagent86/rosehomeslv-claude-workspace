# CLAUDE.md — Rose Homes LV / Clients

Active people in the pipeline. **Confidential** — client data stays here, never copied into other businesses or public artifacts.

- **Buyers/** — one folder per buyer/couple. `/cma` (buyer Word docs) saves here.
- **Listings/** — one folder per seller listing (address as folder name). Source of truth for `listing-marketing`, `reverse-prospecting`, `weekly-update`, `ig-ads`. Contains data sheets, marketing packages, Listing Photos, phase folders. `Listings Lost/` holds lost deals.
- **Transactions/** — per-address active-deal working folders (`transaction.json` etc.), driven by the transaction-coordination skill. **Git-ignored** (private).
- **Lisa-Jones-TC-Process-Breakdown.md** — TC process reference.
