# Flagged Reels for Liker-DM

By default, liker-DM reads the likers of your **most recent ~6 reels**. Use this file only to OVERRIDE that with a focused set (e.g. during a push on one listing or a viral reel).

- Leave the Active list empty -> the scout uses your recent reels automatically.
- List one reel URL per line under "Active" -> the scout uses ONLY those reels. Lines starting with `#` are ignored.

## Active

# (empty = use recent reels. To focus, add URLs below, e.g.)
# https://www.instagram.com/reel/ABC123/

## Notes

- Likers are a weaker audience than followers and share the same daily DM budget, so followers get DMed first.
- Realtors and brokers are skipped automatically. Other businesses (referral sources) are kept.
