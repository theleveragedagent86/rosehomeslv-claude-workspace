# Rose Homes LV YouTube - Weekly Operating System

One repeatable week. Goal: never miss a publish slot. 2 to 3 videos every week, every week.

---

## Monday - Prep (research + scripts)

- [ ] Run `/local-news` to research Clark County news and build the news video transcript
- [ ] Run `/youtube-manager` to pull MLS data and write the market-update script + SEO package
- [ ] Run `/yt-long` to research and script the long-form relocation / neighborhood video + SEO

## Tuesday - Film (batch, one camera session)

- [ ] Set up lighting and teleprompter once
- [ ] Film long-form relocation / neighborhood video (`/yt-long` script)
- [ ] Film local-news video (`/local-news` script)
- [ ] Film market-update video (`/youtube-manager` script)

## Wednesday - Edit + cut Shorts

- [ ] Edit all three long-form videos
- [ ] Cut 2 to 3 Shorts from the long-form footage
- [ ] Build / confirm thumbnails for each video

## Thursday - Package + schedule

- [ ] Attach full SEO package to each video: title, description, tags, thumbnail
- [ ] Confirm the relocation-guide CTA + link is in every description (https://rosehomeslv.com/moving-to-las-vegas)
- [ ] Schedule the week's uploads to the slots below

## Daily - Engage + route leads

- [ ] Reply to comments within the first few hours of each upload, then check again daily
- [ ] Check Lofty for new relocation-guide leads
- [ ] Confirm the smart plan fired, then personally reach out to warm leads to book a discovery call

---

## Publish slots (hold these every week)

- [ ] **Monday** - Long-form relocation / neighborhood video (`/yt-long`)
- [ ] **Wednesday** - Local-news video (`/local-news`)
- [ ] **Friday** - Market-update video (`/youtube-manager`)
- [ ] **Across the week** - 2 to 3 Shorts cut from the long-form

---

## If the week gets compressed, protect in this order

1. Monday long-form
2. Friday market update
3. Wednesday local news
4. Shorts
