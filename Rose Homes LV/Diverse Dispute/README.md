# Diverse Dispute

Working file for recovering the **$12,000 deposit** paid to Diverse Marketing LLC
(meetDiverse.com) on 2025-12-10.

**Bottom line:** the contract gives a full refund if Diverse fails to provide 12 prospects
within 365 days of the program start date. Program start was **2025-12-19**. The 365-day mark
is **2026-12-19**. Prospects delivered as of 2026-08-10: **zero.** The plan is to stay a normal
client, document everything monthly, and request the refund on 2026-12-19.

## Rules for this folder

- **Do not send anything adversarial before 2026-12-19.** Terminating early risks the deposit,
  because the mandatory-refund clause only fires when Diverse is the party that terminates.
- **Do not mention refunds, the contract, or the 365-day clock** in any email to Diverse before
  that date. Check-ins should read as an ordinary engaged client asking for status.
- **Capture the portal on the 10th of every month** and file it under
  `screenshots/<YYYY-MM-DD>/`.
- **Answer every call** to 702-747-5921 and 810-888-9999 and log it. The contract counts a
  missed prospect call as a delivered prospect.
- Governing law is Florida with exclusive Florida jurisdiction. Have a Florida-licensed
  attorney review anything adversarial before it goes out.
