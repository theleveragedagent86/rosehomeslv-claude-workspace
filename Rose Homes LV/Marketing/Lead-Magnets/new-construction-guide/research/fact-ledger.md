## How chapter writers use this file

1. **If a number is not in this ledger, it does not go in the guide.** There is no second source to check. This file is the whole world.
2. **Cite by claim-id.** Example: "Clark County FHA one unit limit is $541,287 (`fin-fha-limit-clark-1unit-2026`)."
3. **Check the NOT FOUND register before writing any number.** If the subject is on that list, write around it or say plainly that the number is not published.
4. **Check the conflicts section before writing anything on a contested topic.** Do not pick a side that the Executive Editor has not approved.
5. **Confidence column:** `high` means a primary source, current. `medium` means a secondary source or slightly dated material. `low` means a single weak source, so hedge it or drop it.
6. **Every value here was verified on 2026-07-25.** Builder prices, incentives, community counts, license records, and BBB records move within weeks. Anything published later than about 30 days from that date should be re-pulled.
7. **This file contains zero em-dash characters.** Do not introduce any.
