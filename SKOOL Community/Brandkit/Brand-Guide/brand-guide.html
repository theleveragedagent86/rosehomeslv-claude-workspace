How the three assets were reconciled

The two logos genuinely disagreed. Per-family pixel dominance settled it: a flat vector fill shows up as a huge share of its own color family, AI raster noise does not.

Teal #064451 3.2% #104A56 23.6% #0F4C5C 26.9% #0F4C5C Banner and monogram agree and are both clean fills. The wordmark's teal is noisy raster with no dominant value

03   Logos

Five files, all at Brandkit/ root. The two dark variants are new as of 2026-08-19 and are color-corrected to the canonical palette, which the light originals still are not.

leveraged-agent-logo-small.png  ·  1024 × 1024 square monogram, NOT a small logo
leveraged-agent-logo-small-dark.png  ·  new
Naming warning. leveraged-agent-logo-small.png is not a small logo, it is the square monogram at full 1024 × 1024. The name is kept on purpose because roughly 44 copies are bundled under hyperframes-student-kit/video-projects/*/assets/ and composition HTML calls them by these exact filenames. The dark files follow the same naming so they drop in the same way.

Clear space

Minimum clear space is 8% of the placed logo height, on all four sides. Nothing may enter that band, including page edges. At a 400px placement that is 17px per side.

Hatched band = the 8% exclusion zone. Dashed outline = the file's own edge. The file already carries about one cap height of internal padding, so total breathing room lands near 1.5 cap heights.

Minimum size

wordmark floor  ·  240px wide
monogram floor  ·  32px
favicon exception  ·  16px

The wordmark floor is set by its tagline, not its name. "AI workflows for working agents" has a 53px cap height at native size, 3.7% of the file width, so it drops below a 9px legibility floor under 240px. Below 240px, use the monogram instead. The monogram floor is set by the "LA" itself, which occupies 35% of the canvas, so at 32px placed the letters land near 11px. Print floors: 1.25in / 32mm for the wordmark, 0.35in / 9mm for the monogram.

Do

  • Use the light file on light, the dark file on dark
  • Place the wordmark on a flat cream or deep field
  • Use the monogram for square and small slots only
  • Keep 8% clear space on all four sides
  • Copy assets into a project's own assets/, never symlink

Do not

  • Recolor either mark
  • Put the light file on a dark surface
  • Stretch, rotate, drop-shadow, or outline the mark
  • Put the wordmark on a photo
  • Use the monogram where the wordmark fits
  • Mix Rose Homes LV realtor branding into this, or the reverse

04   Typography

Set by Ryan 2026-08-18. Poppins for headlines at 600 and 700 with -0.02em tracking, Inter for body at 400 and 500 with 1.5 line-height.

Stop doing the busywork
Poppins 600 subhead, tracking -0.02em
Inter 400 body at 1.5 line-height. Most agents lose the first hour of every day to follow-up that a workflow could have handled before they woke up. The point of this community is not more tools, it is fewer decisions.
Inter 400 at teal-muted, for captions and secondary copy.
headline Poppins 600 / 700 · tracking -0.02em    body Inter 400 / 500 · line-height 1.5
Poppins is not installed on this Mac. Anything rendered locally right now falls back to Futura. Install it before rendering brand work: brew install --cask font-poppins. This page loads Poppins from Google Fonts, so it renders correctly in a browser regardless. This typography does not apply to the YouTube thumbnail template, which Ryan locked to its own stack on 2026-07-16.

Still open

  • No tagline-free wordmark lockup. That is the standard asset for placements under 240px where the monogram is too abstract. Worth generating.
  • The light originals are not color-corrected. Only the dark variants are. Remapping the light files risks visible banding on the wordmark's noisy teal, so they were left alone deliberately.
  • No vector source. Every asset is a raster PNG, so none of it scales cleanly past native size or prints crisply at large format.
