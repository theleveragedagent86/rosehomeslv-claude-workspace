Palette v4 candidates: no teal, no gold
None of these are adopted. v1 is still the shipping brand. Six replacement palettes. Five are built from colors measured off a high-pedigree brokerage in PEDIGREE-BRAND-RESEARCH.md, and Sovereign is the honest exception, called out in its own note. All six keep a white page, cast the ink near-black instead of pure black, and run exactly one accent, which is what nine of the ten researched brands do. Identical markup in every section, only the token values change. Type is held constant here: Poppins 800 display, Inter body. Font alternatives are on v4-type.html. Spec: V4-PALETTES.md.

Electric, modern, high-trust. The easiest of the six to build with, because #1768E5 clears AA as a fill and as text, so there is only one blue to remember.
