# v1-archive

Retired v1.0 "cream / teal / gold" artwork, kept verbatim for auditability. **Nothing
in here is on-brand.** Do not pull from this folder for new work; the shipping system
is v2.0 "Vector" in [../Design-System/](../Design-System/).

| File | What it was |
|---|---|
| `classroom-cover-open-houses.png` | The one rendered v1 classroom cover. Dark-teal radial gradient, gold underline, isometric house icon. Replaced by the type-only `Classroom-Covers/04-open-houses.png`. |
| `classroom-cover-open-houses.json` | Its render config, in the old `bgDark` / `bgLight` / `iconSvgFile` token shape. |
| `icon-open-houses-house.svg` | The isometric house icon: gold `#D9A441`, navy `#0B2E33`, cream `#F5F2EA`. The whole icon system died with v2.0, which is type-only and forbids warm colors. |

The five v1 logo PNGs are **not** archived here. They were overwritten in place on
2026-09-01 because ~29 bundled copies under `hyperframes-student-kit/video-projects/*/assets/`
reference them by filename, so the names had to survive. Recover them from git if needed.
