**Wins to land:** 3, at roughly 14:30, 31:20 and 37:30

## How to read this

- `━━━ DECK · N ━━━` advance the deck.
- `━━━ ▶ CLAUDE CODE ━━━` stop screen-sharing the deck, switch to Claude Code. The block that follows tells you what to do and what to say over it.
- `━━━ ◀ BACK TO DECK · N ━━━` return to the deck at that slide.
- `[brackets]` are directions to you, not spoken.
- Spoken lines are word for word. Make them sound like you, keep the order.

## Before you hit record

- [ ] Deck open in a browser window, slide 1, ready to alt-tab to
- [ ] Claude Code open in a second window, fresh session, nothing in history
- [ ] A genuinely messy desktop. Do not clean it first, that is Win #1
- [ ] One real past client email thread open and ready to scrub on camera
- [ ] The BROKER template open in a text editor so you can paste, not type
- [ ] Do Not Disturb on, notifications off, Slack quit

# PART 4 · BUILD THE BRAIN (17:05 to 33:45)

━━━ ▶ CLAUDE CODE ━━━

**Demo 3: Build the folder structure by prompt. This is Win #2.**

━━━ ◀ BACK TO DECK · 11 ━━━

Now the important part. The file that runs all of it.

Inside your Business Brain there's one file called CLAUDE dot M D. Every time you open Claude Code in that folder, it reads that file first. Before it does anything else.

So this file is your onboarding packet. It's what you'd hand a new team member on day one.

And I've got a framework for it, because when I first did this I wrote three pages and it worked worse. Shorter is better.

━━━ DECK · 12 ━━━

It's called BROKER. Six blocks, under two hundred words total.

[Walk through each, roughly twenty seconds each.]

**B is Business.** Who you are. Your name, your license, your brokerage, how long you've been doing this, solo or team.

**R is Range.** Your farm areas, your price bands, your property types. This is the one people skip and it's the one that matters most. If you write "Las Vegas" you'll get Las Vegas in general. If you write Skye Canyon, Centennial Hills, Summerlin, three fifty to six fifty, single family, now it's writing about your actual business.

**O is Output.** How you write. Short sentences. Sixth grade reading level. No jargon. No em-dashes, and I'm serious about that one, people can smell them. Soft calls to action.

**K is Keep Out.** This is your guardrail block and it's the most important one. Never invent a price. Never invent square footage, a school rating, an HOA amount, or a commission number. Never write anything that describes who should live somewhere. If you don't know something, say NOT FOUND, don't make it up.

**E is Escalation.** When does it stop and ask you. Mine says: before sending anything to a client, before posting anything public, before committing to a date, before quoting a number.

**R is Results.** What you're working on this quarter, so it biases toward that.

[Beat.]

Under two hundred words. I'm going to say that again because everybody ignores it. Under two hundred words. A long file is a file it half reads.

━━━ ▶ CLAUDE CODE ━━━

> "That's it. That file is now the first thing it reads, every time, forever. And I'll put the blank template down below so you're not writing this from scratch."

━━━ ◀ BACK TO DECK · 15 ━━━

One habit before I let you go, and this one is going to save you a lot of confusion.

One task, one window.

Here's what happens to everybody. You open a chat, you work on a listing description, then you ask it about a transaction, then you ask it to fix your landing page, then three hours later you're wondering why the answers got dumb.

They got dumb because the conversation got long and messy. It's carrying all that other stuff around.
