#### Hey, in this video, you're gonna learn:

⚙️ **Build a Custom Skill From Scratch in About Two Minutes** by turning a workflow you already do by hand into a named, reusable command, so a twenty minute task becomes one word.

🧪 **Apply the Should-This-Be-a-Skill Test** by checking whether you have done it twice and will do it again, so you stop automating things that were never worth automating.

⌨️ **Turn Your Skills Into Slash Commands** so launching a listing, drafting a weekly seller update or writing a neighbor letter is a single keystroke instead of a paragraph of instructions.

👥 **Use Sub-Agents Without Wasting Them** by understanding the one condition that makes them worth it, shared context, so you are not spinning up three agents for a job one could do faster.

🧐 **Run a Critic Loop on Everything Client-Facing** by having a separate model review the work before it ships, so nothing goes to a client that has not been graded by something other than the thing that wrote it.

💰 **Stop Overpaying for Simple Work** by matching the model to the task, so reformatting a listing sheet does not cost the same as building a pricing strategy.

🪟 **Fix the Quality Drop You Didn't Know You Had** by adopting one task, one window, so a long messy conversation stops quietly degrading everything you get out of it.

🎯 **Write a Better First Prompt** by learning the recovery move when it takes five tries: ask for the prompt back, then start fresh.

#### In this video, Ryan covers:

There is a point where an agent has been using AI for a month and is still typing the same three paragraph instruction every time they want a listing description. It works, but they have not actually gained any leverage. They have just moved the typing. The gap between using AI and building with it is skills, and it is the widest gap in this entire course.

The system is **Skills, Commands and the Critic Loop**. A skill is a workflow you have done twice, saved with a name, so the twenty minute version becomes a one word version. A command is that skill on a keystroke. The critic loop is a separate model reviewing the output before it ever reaches a client, which is the difference between fast and reckless.

The practical steps are building a skill live from scratch, running it on a real listing, promoting it to a slash command, building the four skills every agent should have first, learning when sub-agents earn their keep and when they do not, setting up a cross-model critic pass, and adopting the one task one window habit.

#### Who this is for:

- **Agents who are already using AI daily** and are retyping the same instructions, who want the leverage they thought they were getting.

- **Agents building toward a team** who need workflows that live somewhere other than in their own head, so the work is transferable.

## Production notes (not for Skool)

**The two-minute live build is the win.** Pick something genuinely small so the speed is the point. Good candidate: a skill that takes an address and returns the three-line "just listed" text for Instagram, Facebook and a text blast. Build it, run it on a real listing, show the output. Under three minutes end to end.

**The four skills every agent should build first**, named on camera so they leave with a to-do list:
1. Listing description (MLS, public and agent remarks in one pass)
2. Weekly seller update
3. Showing feedback follow-up
4. New lead first response

**Sub-agents: be honest that they are usually wrong.** Jack's students overuse this. Give the one condition, shared context, and the analogy:

> "Sub-agents are sending three showing agents to three houses at once. Great when it's three different houses. Pointless when it's three people standing in the same kitchen."

**The critic loop is a non-negotiable, say it that way.** Nothing client-facing ships without a different model reviewing it. Frame it as the AI equivalent of having your TC read the email before you hit send.

**Model choice, in agent terms.** The expensive model for pricing strategy, negotiation approach, anything a client reads. The cheap one for reformatting, batch captions, transcription, renaming files.

> "You do not send your top producer to go install a lockbox."

**Homework:**

> "Think about what you did twice this week. Not something hard, something boring. Go build that as a skill today. It'll take you four minutes and you'll use it forty times this year."

**Close on the Level 4 question:**

> "Here's the problem though. You've got skills now, but every time you open a new window it's still a stranger. It doesn't know the client you talked to in March. So how do you give it a memory that actually holds? Level 4."
