#### In this video, Ryan covers:

Taking a listing live properly means nine separate things have to happen, usually across two days, usually while you are also showing property. Most agents do four of them well, two of them late, and quietly skip the rest. Not because they do not know better, but because there is no version of that day where all nine fit.

The system is **the One-Command Launch**. Every asset a listing needs is generated from one folder of property data, using the voice profile and farm data already sitting in your Business Brain from Level 4. The pre-launch checklist, the Coming Soon campaign, all three write-ups, the social blast, the sphere email, the neighbor letter, the agent outreach and the landing page from Level 2.

The practical steps are setting up the listing folder structure, walking each asset once by hand so you know what good looks like, then collapsing all nine into a single named command and running it live on a real listing.

#### Who this is for:

- **Listing agents taking more than one deal a month** who are losing a full day per launch to work that is important but almost entirely repeatable.

- **Agents who want more listings** and know the marketing package is what wins the appointment, but cannot currently deliver that package at volume.

## Production notes (not for Skool)

**This level absorbs all ten lessons of the existing Module 1.** The detail does not disappear, it moves into the timestamp list and the attached prompt pack. A student who wants only the neighbor letter jumps to 21:00.

**Use a real listing. Ryan's own, ideally one that is currently active or just closed.** This is the differentiator against every generic AI course and it only counts on screen.

**The structure is: walk it by hand, then collapse it.** Do not open with the one-command version. Show the nine pieces individually, roughly two minutes each, so they understand what the command is doing. Then build the command at 28:00 and run it at 32:30. The reveal only lands if they have seen the labor.

**The three-voices point is the single most useful thing in this level for a working agent.** Public remarks sell the lifestyle. MLS remarks carry the facts and the compliance language. Agent remarks are where you signal flexibility, terms and how to write the offer. Put all three on screen at once.

**Fair housing has to be said out loud here, not deferred entirely to Level 9.** One sentence, no lecture:

> "Everything it writes about the property, never about who should live there. It will drift there if you let it. That's in your KEEP OUT block from Level 1 and we're gonna lock it down properly in Level 9."

**Say what stays human.** This protects the whole course from feeling like it is telling agents to automate their relationships:

> "The command writes the sphere email. It does not send it. You read it, you change the two lines that only you would know to change, and you send it yourself. Same with the agent outreach. The leverage is in the drafting, not the sending."

**Weekly seller update attachment.** Lives in `Weekly-Seller-Update-Prompt/`: the prompt (`weekly-seller-update-plan-prompt.md`), a 2-page Vector quick-start guide (`how-to-use.html` source, rendered to `How-to-Use-the-Weekly-Seller-Update-Builder.pdf` with headless Chrome), and `logo.svg`. Same pattern as the Open House Reconnection Prompt. The prompt is a paste-into-Plan-Mode prompt, reverse-engineered from Ryan's real 29 Amber Rock weekly updates. It interviews the student in 10 rounds, then builds a `/weekly-update` skill that produces the branded seller report, the CRM paste file and the seller email draft every week. Seller names and emails from that listing are deliberately left out. Not on the timestamp list yet; mention it in the 35:45 "what you still do yourself" beat or add a timestamp when scripting.

**Open houses:** touch the listing-marketing side here in one beat and point to the Open House OS bonus drop for the full lead-gen system.

**Scheduling:** if they want the Coming Soon sequence to fire on a schedule rather than on command, point to the Cowork OS bonus drop. Do not teach it here.

**Homework:**

> "Next listing you take, run this before you do anything by hand. Then fix what it got wrong. That's how the skill gets good, and it takes you about ten minutes."

**Close on the Level 6 question:**

> "Alright, so it's live and you got it under contract. Congratulations, now the actual work starts, and this is where deals fall apart. Level 6."
