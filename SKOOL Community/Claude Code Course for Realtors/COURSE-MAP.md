# Claude Code Course for Realtors: Course Map

One Skool classroom tile. Level 0 through Level 10, plus three bonus drops.
**Carried artifact:** the Business Brain folder. Every level adds a layer to the same folder.

**Core ladder: 11 videos, roughly 5h 10m. With bonus drops: 14 videos, roughly 5h 40m.**

## Named frameworks in this course

| Name | Level | What it is |
|---|---|---|
| **The Business Brain** | 0, built in 1 | The folder every level upgrades. The carried artifact. |
| **BROKER** | 1 | The `CLAUDE.md` framework: Business, Range, Output, Keep out, Escalation, Results. Under 200 words. |
| **The 5-8 Folder System** | 1 | Five to eight thematic folders mirroring how the business runs |
| **The Three-Step Page System** | 2 | Competitive intelligence, then design brief, then parallel build |
| **The Critic Loop** | 3 | A separate model reviews anything client-facing before it ships |
| **The Three Tiers of Memory** | 4 | BROKER file, folder structure, then long-term voice + data + wiki |
| **The One-Command Launch** | 5 | Nine launch assets from one folder of property data |
| **The AI Transaction Coordinator** | 6 | A folder per deal, plus commands that run against it |
| **The Five-Step Build Method** | 7 | Question, delete, simplify, accelerate, then automate |
| **Design as Code** | 8 | Colors, type and spacing as tokens in `brand.md` |
| **The Four Permission Tiers** | 9 | Read-only, reversible, external, irreversible |
| **Prompts Are Not Permissions** | 9 | The rule of Level 9 |
| **The Money Loop** | 10 | Find the constraint, more/better/new, apply, measure, repeat |
