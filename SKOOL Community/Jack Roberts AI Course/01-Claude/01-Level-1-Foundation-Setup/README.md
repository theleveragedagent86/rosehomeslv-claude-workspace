#### Hey, in this video, you're gonna learn:

💻 How to install Claude Code and Anti-Gravity (Google's IDE) on your desktop — and why having both gives you more flexibility than the Claude desktop app alone

🧭 How to navigate the Claude desktop app's three modes — Chat, Co-work, and Code — and when to use each one for different types of tasks

⚙️ How to configure Claude Code permissions — Ask First, Accept Edits, and Bypass — and which mode to use based on your trust level and task type

🔑 How to choose between Claude Pro vs. Max plans and when to upgrade — including how to use API keys to reduce cost while maintaining performance

🛠️ How to use key slash commands in Claude Code — /context, /clear, and /compact — to manage context rot and maintain model performance over long sessions

🔌 How to connect Claude to external tools via MCP connectors — including Google Drive, Firecrawl, GitHub, Granola, and the YouTube API — at three levels: built-in, custom, and CLI

📁 How to set up a project folder structure with 5–8 core projects and a [CLAUDE.md](http://CLAUDE.md) file using the BALLAST framework — to give Claude persistent, structured instructions under 200 words

#### In this video, I cover:

You'll start by understanding the core concept of Claude Code: it's not the model itself but the environment — the "Iron Man suit" — that unlocks capabilities unavailable in the browser version.

You'll then install both the Claude desktop app and Anti-Gravity, connect your Claude account, and get a full walkthrough of the interface across Chat, Co-work, and Code modes.

You'll learn how context rot works — why model performance degrades over long conversations — and how to use /clear and /compact to keep your context window healthy and accurate.

You'll see a live breakdown of Claude's three permission modes, when to use each, and how to use "my stated intention is" as a prompt hack to reduce unnecessary permission prompts.

You'll discover how to connect Claude to real tools — Google Drive, Firecrawl, GitHub via CLI, Granola for meeting notes, and the YouTube API — using built-in connectors, custom MCP URLs, and API keys, with live demos of each.

You'll finish by setting up a 5–8 project folder system on your desktop, each with a [CLAUDE.md](http://CLAUDE.md) file using the BALLAST framework — your project operating manual that primes Claude with crisp, structured instructions every time you start a new build.

#### Who this is for:

- Complete beginners to Claude Code who want a guided, step-by-step setup from install to first live build — including how to navigate the interface, manage permissions, and choose the right plan.

- Business owners and agency builders who want to connect Claude to their existing tools (Google Drive, GitHub, meeting notes, APIs) and set up a clean project infrastructure before tackling real client work.
