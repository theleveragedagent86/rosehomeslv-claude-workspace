#### Hey, in this video, you're gonna learn:

🎨 How the Claude Code Design Agentic OS works — a locally-running design system that connects to Higgsfield, Krea AI, and OpenRouter to generate, remix, and manage images with full cost transparency per generation

🖼️ How to create Design Recipes inside the Palette feature — pre-saving reference images and prompt instructions so you can batch-generate consistent thumbnail variations (e.g. same layout, swapped background and text) in one click

🔍 How Magic Search and Visual Understanding work — using a cheap OpenRouter model to OCR and describe every image on your computer so you can search your entire local library by visual content, not just file name

💰 How to track AI image generation spend across all connected tools — Krea AI, Higgsfield, OpenAI, and OpenRouter — from a single insights dashboard with live credit balances

🔗 How to connect Krea AI and Higgsfield CLI to the Design OS — API key setup, model selection (e.g. Nana Banana 2), resolution, and output count — with cost shown before every generation

#### In this video, Jack covers:

You'll start by seeing the Claude Code Design OS running locally — a unified design environment that connects to multiple image generation tools and shows you exactly what each generation will cost before you commit.

You'll learn how the Palette feature works: create named Design Recipes by pre-loading reference images and prompt instructions, then generate multiple variations in the background without manually re-entering prompts — ideal for consistent YouTube thumbnail production at scale.

You'll discover the Library and Magic Search system: the OS indexes every image on your computer, and with Visual Understanding enabled (using a cheap OpenRouter model), it reads the actual content of each image — so searching "the price broke" surfaces a thumbnail with that text even if the file has no relevant name.

You'll see the Insights dashboard, which gives you a live breakdown of credits and spend across every connected tool — OpenRouter, OpenAI, Higgsfield, and Krea AI — all in one place.

You'll finish with a preview of what's coming next: this is described as Level 1, with further builds planned exclusively for community members.

#### Who this is for:

- Content creators and agency owners who generate images at volume — thumbnails, ad creatives, social media visuals — and want a single local OS to manage prompts, reference images, model selection, and cost tracking without switching between platforms.

- Builders already using Claude Code who want to extend their agentic stack into visual design — connecting Higgsfield, Krea AI, and OpenRouter under one interface with design recipe automation and full-library image search.
