#### Hey, in this video, you're gonna learn:

🤖 Why Hermes is an agent and not a chatbot — and how the chatbot vs. agent distinction (vending machine vs. chief of staff) changes what AI can actually do for you

🧠 How Hermes's four-layer anatomy works — Gateway (senses), Brain (model), Body (tools: terminal, browser, files, computer), and Memory — and why each layer matters

🔁 How Hermes's self-evolving four-step learning loop works — observe, write to memory, review, and improve — so it gets better the more you use it

📄 What [soul.md](http://soul.md) is and how to fill it out — the single markdown file that gives Hermes your personality, preferences, business context, and voice

🔀 When to use Hermes vs. Claude Code — Hermes for always-on, on-the-go, long-term memory; Claude Code for deep, desktop-based building sessions

🌐 How Hermes connects to any model or tool — Claude Opus, GPT, DeepSeek, Grok, local Ollama models, MCP servers, Clay, and more — via a model-agnostic harness

⏰ How to use cron jobs (scheduled missions) inside Hermes — including proactive morning briefings with calendar, email, and priority summaries

#### In this video, I cover:

You'll start by understanding the single most important distinction in AI right now: the difference between a chatbot and an agent.

You'll see why Hermes is not just a question-answering tool — it can draft emails, do deep research, access and amend files on your desktop, browse the internet, move your mouse, and message you proactively every morning.

You'll then get a breakdown of the four-layer anatomy of Hermes: the Gateway (always-on listener across every channel), the Brain (the model that reads, reasons, and picks the right tool), the Body (terminal, browser, files, computer, MCP connectors), and the Memory (the persistent knowledge base that makes Hermes uniquely yours over time).

You'll learn how the [soul.md](http://soul.md) file works — a single markdown document that defines Hermes's personality, your preferences, your business context, and your voice — and how to fill it out using speech-to-text tools like Glider or Claude itself.

You'll understand when to use Hermes vs. Claude Code: Hermes for always-on, cross-channel, long-term tasks; Claude Code for focused, desktop-based build sessions — and why both can technically overlap but serve different rhythms.

You'll finish with a preview of what comes next: installing Hermes, setting up OAuth vs. API keys, running it on a VPS, Docker, scheduling, and making it permanent.

#### Who this is for:

- Beginners entering the Hermes Masterclass who need a foundational understanding of what an agent actually is, how it differs from a chatbot, and why the harness around the model matters more than the model itself.

- Business owners and builders who want a personal AI operating system that remembers them, runs on a schedule, works across Telegram and WhatsApp, and improves autonomously over time.
