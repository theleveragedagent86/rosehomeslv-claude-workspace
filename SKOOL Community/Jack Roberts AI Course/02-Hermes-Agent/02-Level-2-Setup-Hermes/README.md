#### Hey, in this video, you're gonna learn:

🖥️ How to choose between three Hermes installation environments — local machine, Docker, and VPS — and the honest trade-offs of each (including why most VPS recommendations online are sponsored)

⚡ How to install Hermes agent on your local machine with a single terminal command — and why this is the fastest path to a working setup

🐳 How Docker containerization works — images vs. containers — and how to use Claude to walk you through the full Docker setup without manual configuration

🔑 How to connect Hermes to OpenRouter to access every available AI model (Claude Opus 4.8, DeepSeek V4 Pro, GPT, Gemini, and more) via a single API key

📱 How to connect Hermes to Telegram as your messaging interface — including QR code authentication and locking it to a single user ID for security

⏰ How to set up scheduled missions (cron jobs) inside Hermes — including a morning brief with weather, calendar, email, and priority suggestions

💾 How to back up and version-control your Hermes agent using a private GitHub repo — so you can restore any previous version of Hermes at any time

#### In this video, I cover:

You'll start by understanding the three environments where Hermes can run: on your own machine (recommended for beginners), inside a Docker container (for isolated, reproducible setups), or on a VPS (always-on cloud hosting) — with a transparent breakdown of why VPS is pushed so heavily by other creators and why local is the better starting point.

You'll then install Hermes on your local machine using a single terminal command, go through the full setup flow, and see how to select your preferred AI model and configure your API keys.

You'll see a live Docker setup walkthrough — including downloading Docker Desktop, using Claude to interpret and execute the setup guide, understanding the difference between Docker images and containers, and running Hermes inside a containerized environment using the `herk` terminal alias.

You'll learn how to connect Hermes to OpenRouter to gain access to every major model on the market, and how to set a spending cap on your API key to keep costs under control.

You'll configure Telegram as your Hermes messaging interface and restrict access to your own user ID so no one else can interact with your agent.

You'll finish by setting up a daily GitHub backup of your entire Hermes configuration — creating a private repo that saves a version-controlled copy of your agent every day, so you can roll back to any previous state if something breaks.

#### Who this is for:

- Beginners setting up Hermes agent for the first time who want a clear, unsponsored breakdown of which installation method to use and a step-by-step walkthrough of the full setup process.

- Builders who want their Hermes agent backed up, version-controlled, and connected to multiple AI models — without being locked into a single provider or cloud platform.
