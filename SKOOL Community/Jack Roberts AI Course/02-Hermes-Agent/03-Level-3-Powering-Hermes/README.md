#### Hey, in this video, you're gonna learn:

🔌 How to connect Hermes to Gmail and Google Calendar using Zapier MCP — including how to pass credentials securely without exposing them in chat logs

📋 How to connect Hermes to Granola (meeting note taker) via MCP — and query past meetings, commitments, and action items directly from Hermes

🔀 How to switch Hermes between any AI model on demand — Claude Opus 4.8, GPT 5.6 Sol, DeepSeek V4, GLM 5.2, and more — using OpenRouter as a single master API key

🧭 How the model routing decision tree works — using frontier models (Claude Fable 5, GPT 5.6 Sol) for planning and architecture, cheap models (DeepSeek V4 Flash) for execution and grunt work, and local models for private offline tasks

🖥️ How to download Ollama and run local AI models (Qwen 3, GPT RSS) 100% offline on your own hardware — with no internet connection required — and connect them to Hermes as a custom model endpoint

🏛️ How to set up the Pantheon — a named persona system inside Hermes where each role (e.g. "The Oracle") has its own model, system prompt, and task assignment

🤝 How the Ministry of Agents (Mixture of Agents) works — sending one question to multiple models simultaneously (DeepSeek, GLM 5.2, GPT 5.5) and having a lead model synthesize the best combined answer

#### In this video, I cover:

You'll start by learning the core philosophy: you own the Hermes agent harness, and you simply rent whichever AI model ("brain") is best for the task — swapping models in and out without rebuilding anything.

You'll then connect Hermes to your real-world tools: first Granola (meeting notes) via MCP with a single prompt, then Gmail and Google Calendar via Zapier MCP — including the exact process for passing credentials securely through the terminal so they never appear in chat logs.

You'll see how to use OpenRouter as a single master API key that unlocks every major model on the market, set monthly spending limits, and switch Hermes between models mid-conversation using the `/model` command or natural language.

You'll learn the routing decision tree: which tasks belong to frontier models like Fable 5 (architecture, design, strategy, review) vs. cheap models like DeepSeek V4 Flash (repetitive execution, grunt work) — and why using the wrong model for the wrong task wastes cost without improving results.

You'll download Ollama, install a local model (Qwen 3 or GPT RSS), expand its context window beyond the 4,096-token default, and connect it to Hermes for 100% offline, private AI — no internet connection required.

You'll finish by setting up the Pantheon (named agent personas with dedicated models and system prompts) and the Ministry of Agents (mixture-of-agents mode where multiple models answer the same question independently and a lead model synthesizes the best result).

#### Who this is for:

- Hermes users who have completed setup and are ready to connect their agent to real tools — email, calendar, meeting notes — and unlock multi-model switching for different types of tasks.

- Builders and agency owners who want to run a cost-efficient AI stack by routing the right tasks to the right models, including free local models via Ollama for offline or privacy-sensitive work.
