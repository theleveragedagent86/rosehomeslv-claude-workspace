## System demoed
The DO framework in VS Code with Claude Code. **D**irectives are plain-language markdown SOPs. **O**rchestration is the agent deciding order and routing. **E**xecution is Python scripts the agent writes itself. Live: prompt one grabs a sales-call transcript and produces a full PandaDoc proposal with quantified problems, ROI math, scope, and a payment-enabled invoice. Prompt two ("onboard them") runs a staggered welcome-email sequence from multiple team addresses, casualizes company names for cold copy, scrapes and filters an Apify lead list (auto-tuning filters until the sample passes an 80% quality bar), writes three split-tested Instantly campaigns modeled on his highest historical performers, and populates a Google Sheet knowledge base for an auto-reply bot. Build method: compile every SOP, hand each to the agent, test once and let it loop until it works, rinse and repeat, then write a meta directive that chains all the directives.
