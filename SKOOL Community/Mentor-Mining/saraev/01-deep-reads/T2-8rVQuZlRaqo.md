## System demoed
Four components. 1) Shared human and AI workspace: Linear with five statuses and an "agent ready" label. Moving a labeled task to next fires a Linear webhook to a server where an agent (he calls the runs "Nick OS agent run") picks it up, consults a knowledge base of past task completions and preferences, posts a plan into the issue, works, then sets itself to waiting when it needs him. It has three things: workspace context, a knowledge base, and stored credentials for signing into services. 2) Capture: a global hotkey on desktop and an iPhone action button shortcut that create Linear issues in seconds, plus command-G to attach a brief and push notifications when an agent is blocked. 3) Evals: standardized checklists the agent must self-score against before surfacing work. Examples given are a visual-asset check (text renders clean, no melted characters, legible at thumbnail size, correct 1280x720 or 1920x1080 shape, faithful to brief) and a "was this done the way that Nick thinks" check scoring five principles zero to two with a fail below seven, which loops the agent until it passes. Tone rules include stripping "all of the basic LLM-isms ... like m-dashes and stuff like that." 4) QA: he is the final human gate, spending his time scoping and verifying rather than producing.
