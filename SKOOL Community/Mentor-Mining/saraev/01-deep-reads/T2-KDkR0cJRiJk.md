## System demoed
A four-stage asset pipeline that ends in a hand-off to a coding agent. (1) Generate a widescreen stylized still with Nano Banana Pro / GPT image two on Higgs Field [sic?], 1K, batch of 2, prompt style is "Renaissance old master oil painting study"; (2) image-to-video with C Dance 2.0 [sic?], 4 seconds, 16:9, 1080p; (3) hand the MP4 plus his prepared "dither prompt" to Claude in the Claude desktop app Code tab on local mode, which chops the video to roughly 11 frames per second and applies a black-and-white dithering shader as an animated above-the-fold background, with mouse-reactive effects; (4) ask it in plain English for three or four font/color/placement variants, then deploy to Vercel by pasting a team ID and a 1-hour-expiry API token into the chat. He deliberately builds only the hero section, not the full page.
