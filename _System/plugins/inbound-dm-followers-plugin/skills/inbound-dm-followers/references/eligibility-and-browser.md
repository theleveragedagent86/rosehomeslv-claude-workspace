# Eligibility Filter and DM Mechanics

## DM Eligibility Filter (re-confirm before every DM)

The researcher already filtered, but glance at the profile again before sending. Do NOT DM unless ALL are true:
- Has at least one post. A missing profile picture or default silhouette is fine, do not skip for that.
- Handle is not an obvious bot (random digit strings, gibberish, spam-word salad).
- Is not a zero-info private account.
- **Is not a real estate agent or broker.** Ryan never DMs competitors. Signals: "Realtor", "REALTOR", "Real Estate", "Broker", "Realty", "Homes by", a license like `S.0123456`, a brokerage name.

**Allowed (DM them):** regular people, plus non-competing businesses / service providers that can be referral sources (divorce attorneys, landscapers, contractors, photographers, loan officers / lenders). If you skip someone, still check them off in the log with a short reason so the researcher does not re-add them.

## Sending a DM in Chrome (Cowork)

Use Ryan's real Chrome, logged in as `@rosehomeslv`.

1. Go to `https://www.instagram.com/<handle>/`.
2. **Confirm the handle on the page matches** the person you mean to DM. This is your correctness check.
3. Click the **Message** button on their profile (this opens the thread with that exact person).
4. Click the message input, type the personalized, variant-selected message.
5. Send, then read the thread and **confirm your message bubble appears** with the text you sent.
6. Only after that, check the person off in the research log and append to `dm-history.md`.

## Abort on uncertainty

Skip the person (leave them unchecked, do not retry blindly) if: the profile handle does not match, you cannot find the Message button or input, or you cannot confirm the message sent. A missed DM costs nothing; a DM to the wrong person or a double-send is harmful.

## Pacing and stop protocol

- 60 to 120 seconds between DMs, randomized.
- Stop the whole run immediately on "Action Blocked", "Try Again Later", a verify/identity challenge, a logout, or a DM failing twice. Write a `PAUSE` file in the shared folder with the reason and tell Ryan. A block is the warning before a ban.
