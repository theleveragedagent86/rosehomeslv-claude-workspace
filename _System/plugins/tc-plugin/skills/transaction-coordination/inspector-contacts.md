# Preferred Home Inspectors

Update this file to change the inspector options presented to buyers.

This is the **canonical block**. Templates that send inspector options (buyer-new-construction Template 2, buyer-resale Template R2) must reproduce the intro paragraph and all three listings below verbatim.

**Voice rule:** the intro paragraph is Ryan speaking, so it is always first person singular ("I", "my clients", "let me know"). The bullets under each company are that company's own marketing copy, so "our"/"we" inside them stays as-is.

**URL rule:** write the plain domain only. Never paste a Gmail-wrapped `https://www.google.com/url?q=...` link.
